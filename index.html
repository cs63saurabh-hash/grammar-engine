Pāṇini's Aṣṭādhyāyī as a
Rule-Based Grammar Engine

A working parser that resolves Sanskrit case-endings (vibhakti) into semantic roles (kāraka) — subject, object, instrument, recipient, source, possessor, location — using the same rule-precedence principle Pāṇini formalised roughly 2,500 years ago.

01

Problem statement

Rule-based systems — parsers, lexers, expert systems — must resolve conflicts when more than one rule could match the same input. Pāṇini solved this exact problem for Sanskrit grammar via the utsarga–apavāda principle: a general rule always yields to a more specific exception rule. This engine implements that principle directly — the same rule-precedence logic used by compiler lexers and semantic-role-labelling systems today.

05

Algorithm specification

// RULES sorted once: highest priority, then longest suffix, first
// — this ordering IS the utsarga-apavada precedence
SORTED_RULES = sort(RULES, by: priority desc, then suffix length desc)

function analyzeWord(word):
    w = lowercase(trim(word))
    for rule in SORTED_RULES:
        if w ends with rule.suffix and length(w) > length(rule.suffix):
            stem = w minus rule.suffix
            return {word, stem, rule.suffix, rule.vibhakti, rule.karaka}
    return {word, unrecognized: true}   // fails gracefully

function parseSentence(sentence):
    return [analyzeWord(w) for w in split(sentence)]

function summarizeSentence(sentence):
    analyses = parseSentence(sentence)
    return group analyses by karaka

07

Complexity & limitations

Complexity

  • Time: O(R·n) per word (R = rule count, n = word length); O(W·R·n) per sentence. With a fixed small R this is effectively O(W·n).
  • Space: O(R) for the rule table plus O(W) for returned analyses — no recursion, no parse tree.

Limitations

  • Only nominal case endings are modeled — verbs are correctly reported as unrecognized.
  • Sandhi (sound-change at word boundaries) is not applied.
  • The suffix list is illustrative, not exhaustive — extending the RULES array requires no other code changes.

08

Conclusion

Pāṇini's ~2,500-year-old utsarga–apavāda precedence principle maps directly onto a core computer-science idea — deterministic conflict resolution in rule-based systems. A compact, fully-tested rule engine is enough to recover grammatical meaning from Sanskrit case endings, with no external NLP libraries required.
